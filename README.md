# 출근길 한마디 (안드로이드 앱)

아침에 정한 시간이 되면 폰 알림으로 응원 문구 한 줄이 도착하는 앱입니다.

## 앱 기능
- 정한 시간에 알림으로 문구 도착 (앱을 꺼 둬도, 폰을 껐다 켜도 유지)
- 평일만 받기 (월~금) 선택
- 힘내기 · 위로 · 웃음 종류별 문구 보기
- 카톡 등으로 문구 보내기, 복사
- "지금 알림 한 번 받아보기"로 바로 시험

## 설치 파일(APK) 만드는 방법 — GitHub 이용 (무료)
1. github.com 가입 → 오른쪽 위 `+` → **New repository**
   - 이름: `MorningWord`, **Public** 선택 → Create
2. 만든 저장소 화면에서 **uploading an existing file** 클릭
3. 압축을 푼 `MorningWord` 폴더 **안의 내용 전부**(.github 폴더 포함)를 끌어다 놓기 → **Commit changes**
   - `.github` 폴더가 안 보이면: 윈도우 탐색기 [보기] → [숨긴 항목] 체크
4. 위쪽 **Actions** 탭에서 초록 체크가 뜰 때까지 3~5분 기다리기
5. 폰으로 `github.com/내아이디/MorningWord/releases` 접속 → `MorningWord.apk` 받기

## 폰에 설치
1. 받은 `MorningWord.apk` 누르기
2. "출처를 알 수 없는 앱" 경고가 나오면 → 설정 → **이 출처 허용** 켜기
3. 설치 → 앱 열기 → **알림 허용**
4. 시간 정하고 **알람 켜기**

## 알림이 안 올 때 (갤럭시)
설정 → 애플리케이션 → 출근길 한마디 → 배터리 → **제한 없음** 으로 바꾸기
